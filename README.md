📘 Tabella Voti – Esercizio PHP

Questo repository contiene un esercizio scolastico realizzato in PHP che genera dinamicamente una tabella di voti utilizzando array, funzioni PHP e output HTML.

📌 Descrizione del progetto

Il progetto crea una tabella contenente un elenco di studenti e materie, organizzati attraverso array.
La tabella viene costruita e popolata dinamicamente tramite tre funzioni principali:

creaTabella($materie) → genera l'intestazione HTML con le materie.

inizializzaPersone($persone, $materie) → associa a ogni studente la lista delle materie.

popolaTabella($persone) → stampa i dati nella tabella.

Il risultato è una tabella ordinata e generata completamente lato server.

🧠 Obiettivi didattici

Questo esercizio ha lo scopo di:

consolidare l'uso degli array in PHP;

esercitarsi nella definizione e chiamata di funzioni personalizzate;

comprendere come PHP può generare HTML dinamicamente;

separare la logica (PHP) dalla presentazione (CSS).

💻 Tecnologie utilizzate

PHP 8+

HTML5

CSS (file style.css incluso)

📘 Grades Table – PHP Exercise

This repository contains a school exercise written in PHP that dynamically generates a grades table using arrays, custom functions, and HTML output.

📌 Project Description

The script creates a table with a list of students and subjects, organized through PHP arrays.
The table is built and filled using three core functions:

creaTabella($materie) → builds the HTML header with subjects.

inizializzaPersone($persone, $materie) → links each student to all subjects.

popolaTabella($persone) → prints the table rows dynamically.

The entire output is generated server-side.

🧠 Learning Goals

This exercise helps practice:

working with arrays in PHP;

defining and calling custom functions;

generating dynamic HTML using PHP;

separating logic (PHP) and design (CSS).

💻 Technologies Used

- PHP 8+

- HTML5

- CSS
